---
name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, poke holes in a design, or uses any 'grill' trigger phrases.
---

Interview the user relentlessly about every aspect of the plan until you reach a shared understanding.
Walk down each branch of the design tree, resolving dependencies between decisions one by one.
Ask everything that is askable now in one round, and hold back questions that depend on an answer you have not heard yet.

Ask every question through the AskUserQuestion tool, with your recommended answer as the first option.
Free-text answers often reshape the question rather than pick an option; read them as decisions too.

If a question can be answered by exploring the codebase, explore the codebase instead of asking.
Do not act on the plan until the user confirms the understanding is shared.
